# Group 4 Project 2

Use [group4_project2_AL](group4_project2_AL/README.md) for the source and setup commands,
or download [the portable ZIP](group4_project2_AL.zip).

This revision runs available simulation tasks and holds a station before a failed
movement while independent work continues. Start/Pause/resume and that behaviour
were tested with five products selected. It is not a validated five-product batch:
the loaded-carrier pickup and closed-box stacking paths still need adjustment.

The project includes 40 solved joint reference movements, the V6 models, USB/Wi-Fi
setup instructions and an updated four-page report. 106 automated tests pass.
Physical arm control still needs the university driver mapping and calibration.

The older src.zip is an archive; use group4_project2_AL for current work.
